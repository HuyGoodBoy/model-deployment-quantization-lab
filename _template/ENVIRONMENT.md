# Môi trường ngày YYYY-MM-DD

**Trạng thái:** chưa có phiên chạy.

Khi thực nghiệm, ghi rõ:

- OS, CPU, RAM, GPU/VRAM và driver.
- Python, dependency thực cài, lock file và converter.
- Model/checkpoint revision, hash và input contract.
- Preprocessing/tokenizer; dataset/calibration/evaluation revision, hash, seed và số mẫu.
- Runtime/provider/delegate, thread, batch, warm-up/runs và phạm vi timer.
- Timestamp, run ID, power/thermal metadata nếu thu được.

Thông tin lấy từ báo cáo bên ngoài phải dẫn nguồn và phân biệt với inventory đã kiểm trên máy.
