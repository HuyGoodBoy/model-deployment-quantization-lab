# Báo cáo công việc: đánh giá model trên Android thật

**Ngày báo cáo: 08/10/2026.**

## 1. Mục tiêu công việc

Tiếp tục pipeline MobileNetV2 đã convert sang ONNX/TFLite FP32: chạy trên Android, so sánh toàn bộ output với TensorFlow gốc và đo latency. Đã hoàn thành trên **thiết bị thật Google Pixel 8a** qua Firebase Test Lab, không cần giả lập trên PC/VPS.

## 2. Nội dung đã tìm hiểu

Ứng dụng Android dùng ONNX Runtime Java hoặc TensorFlow Lite Java để chạy model. Instrumentation test tự đưa input vào hai runtime, lưu output và đo thời gian. Firebase Test Lab cung cấp thiết bị và thu artifact; các metric sai khác được tính bằng Python từ output thật, không phải biểu đồ performance có sẵn trong Firebase.

App không cần Firebase SDK hay `google-services.json` để chạy instrumentation test. Hướng dẫn thực hành: [Android README](../../android/README.md).

## 3. Cách thực hiện và điều kiện thử nghiệm

- Model: Keras MobileNetV2 alpha=1, pretrained ImageNet; dùng nguyên hai file ONNX/TFLite đã export ngày 07/10, **FP32, chưa quantize**.
- Thiết bị: Google Pixel 8a, Android 14/API 34, ARM64; model ID `akita`, loại **PHYSICAL** trong Test Lab.
- Input: cùng tensor RGB NHWC `[1,224,224,3]`, FP32, đã preprocess trên PC. Output: 1.000 xác suất softmax mỗi ảnh. Kiểm tra SHA-256 model/input trước khi chạy.
- ONNX Runtime Android **1.20.0**, CPUExecutionProvider, ORT_ENABLE_ALL; TFLite **2.15.0**, XNNPACK bật. Log xác nhận tạo XNNPACK delegate; không kết luận tất cả operator đều được delegate.
- Tắt NNAPI và không thêm GPU delegate. Batch=1, 1 thread intra-op, 30 warm-up, 200 lượt đo mỗi runtime, lặp lại ảnh `grace_hopper.jpg`.
- Thứ tự: ONNX rồi TFLite, cùng test process. Timer gồm gọi inference API Java, copy input/output và tạo tensor; loại load model/file, preprocess, ghi file và tính metric.
- Nhiệt độ pin: ONNX trước/sau 32,7°C; TFLite trước 32,7°C, sau 32,6°C. Thermal status báo 0 trong các lần lấy metadata. Đây là nhiệt độ pin, không phải nhiệt độ CPU.
- Test đo lúc 09:47:55 ngày 08/10/2026 (UTC+7). Firebase báo **Passed, 1 test case**, test time 14 giây; đây là tổng thời gian test, không phải latency mỗi inference.

## 4. Kết quả đánh giá sai khác output

Tham chiếu là output TensorFlow FP32 trên PC, với cùng hai input. Metric số học tính trên **2 ảnh × 1.000 lớp**, không chỉ class dự đoán.

| Metric | ONNX trên Android | TFLite trên Android |
|---|---:|---:|
| MAE | 1,64218e-9 | 9,96460e-10 |
| RMSE | 3,01082e-8 | 1,60368e-8 |
| Max absolute error | 1,25170e-6 | 6,55651e-7 |
| Relative L2 | 1,09917e-6 | 5,85464e-7 |
| Cosine | 0,99999999999948008 | 0,99999999999993294 |
| SNR | 119,179 dB | 124,650 dB |
| Top-1 agreement | 100% (2/2 ảnh) | 100% (2/2 ảnh) |
| Top-5 overlap | 100% | 100% |
| Allclose | True | True |

Allclose kiểm tra từng phần tử với `abs(candidate-reference) <= 1e-5 + 1e-4*abs(reference)`. SNR = `10*log10(sum(reference²)/sum((candidate-reference)²))`. Hai runtime đạt tolerance đã đặt, output gần model gốc nhưng không giống hệt từng phần tử.

## 5. Kết quả đánh giá tốc độ trên Android

| Runtime | Mean | Median | P95 |
|---|---:|---:|---:|
| ONNX Runtime | 36,004 ms | 35,284 ms | 40,406 ms |
| TFLite + XNNPACK | 22,391 ms | 22,092 ms | 24,640 ms |

Trong lượt này, TFLite có median latency thấp hơn ONNX khoảng **37,4%**, tương đương tỷ số latency ONNX/TFLite khoảng **1,60 lần**. Trên PC trước đó ONNX nhanh hơn TFLite; thứ tự tốc độ thay đổi theo môi trường đo. Không so số tuyệt đối Android/PC như thể cùng phần cứng và cùng overhead API.

## 6. Kết luận và giới hạn

Đã chạy thành công hai model FP32 trên Android thật, thu đầy đủ output và 200 mẫu latency cho mỗi runtime. Sai khác số học nhỏ trong hai ảnh mẫu; TFLite nhanh hơn ONNX trong lượt đo CPU trên Pixel 8a này.

- Chưa có tập nhãn thật để tính accuracy. Agreement 100% với model gốc không phải accuracy 100%.
- Chỉ hai ảnh kiểm tra pipeline và một lượt test; chưa đủ để kết luận cho mọi input/điện thoại.
- Hai runtime nối tiếp trong cùng process; thứ tự đo và tải nền có thể ảnh hưởng latency.
- Phiên bản Android/PC khác nhẹ: ORT 1.20.0/1.20.1 và TFLite 2.15.0/2.15.1. Timer Java khác timer Python.
- Chưa đo GPU, NNAPI, quantization, RAM hoặc năng lượng. Thermal metadata không chứng minh thiết bị hoàn toàn không chịu ảnh hưởng nhiệt.

## 7. Hướng thực hiện tiếp theo

Hướng mở rộng: đánh giá nhiều ảnh có nhãn, đảo thứ tự runtime và đo nhiều lượt trên cùng thiết bị trong điều kiện ổn định. Có thể bổ sung cấu hình 4 thread hoặc thiết bị khác thành môi trường riêng. Các bước này chưa thực hiện trong phạm vi báo cáo.
